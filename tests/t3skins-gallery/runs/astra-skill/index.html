Install guidance & source credits +

How to install

Download a skin’s JSON, then in T3 Code open Settings → Appearance, press Add, and drop the file in. On the machine running the T3 server you can also run t3 theme set path/to/skin.json. Built-in fallback: t3 theme set t3-chat.

Three steps to a fresh T3 Code.

  1. Download a skin

    Choose a skin and select “Download JSON”.

  2. Open Appearance

    In T3 Code, go to Settings → Appearance.

  3. Add your skin

    Press Add and drop in the JSON file.

Prefer the terminal?

Run this on the machine hosting your T3 server:

t3 theme set path/to/skin.json

To return to the built-in theme:

t3 theme set t3-chat
