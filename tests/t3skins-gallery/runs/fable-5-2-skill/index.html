T3 Code skins, running live.

On 14 Nov 2026 at 9:41 AM IST, Theo announced that T3 Code can be fully restyled in-app, including custom CSS. This gallery compiles the community skins shared in the days after that, from t3skins.dev, GitHub and X.

Where a theme file is public, the preview runs its real colours and CSS in a mock T3 Code UI, so animated skins actually animate. It works offline: open index.html from this folder.

How to install

  1. Download a skin’s JSON.
  2. In T3 Code, open Settings → Appearance and press Add.
  3. Drop the file in.

On the machine running the T3 server you can also run:

t3 theme set path/to/skin.json

Built-in fallback, if you want the default look back:

t3 theme set t3-chat
