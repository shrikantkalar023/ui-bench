MAKE IT YOURS

New look.
Three small steps.

No setup rabbit hole. Just a JSON file.

  1. 01

    Find your feeling

    Preview a skin. Download its JSON file.

  2. 02

    Give it a home

    In T3 Code, open Settings → Appearance.

  3. 03

    Make yourself comfortable

    Press Add and drop in your file. You’re in.

PREFER THE TERMINAL?

On the machine running your T3 server:

t3 theme set path/to/skin.json

Back to the built-in theme:

t3 theme set t3-chatRead the appearance docs ↗

A community collection

On 14 Nov 2026 at 9:41 AM IST, Theo announced full in-app restyling for T3 Code, including custom CSS. These skins were shared in the days after, across t3skins.dev, GitHub and X. This personal compilation works offline, too: open index.html from this folder.
