About this collection & sources

Following Theo’s announcement on 14 Nov 2026 at 9:41 AM IST, T3 Code can be fully restyled in-app, including custom CSS. This collection brings together skins from t3skins.dev, GitHub and X. Open this page offline or from a static server.

How to install

Download a skin’s JSON, then in T3 Code open Settings → Appearance, press Add, and drop the file in. On the machine running the T3 server you can also run t3 theme set path/to/skin.json. Built-in fallback: t3 theme set t3-chat.
