Try on any T3 Code skin.

Since Theo announced on 14 Nov 2026 that T3 Code can be restyled in-app with custom CSS, people have shared skins on t3skins.dev, GitHub and X. This page collects them. Pick one and the stage below wears it: real palette, real CSS, inside a mock of the T3 Code window, so animated skins move.

Works offline from this folder. Install a skin from Settings → Appearance → Add in T3 Code, or with t3 theme set file.json on the server. A personal compilation, not an official T3 product.

How to install a skin

  1. Download the skin’s JSON from its card or the Details view.
  2. In T3 Code open Settings → Appearance, press Add, and drop the file in.
  3. Or, on the machine running the T3 server, run t3 theme set path/to/skin.json.

To undo, pick another theme in Appearance, or run t3 theme set t3-chat. Theme files remain the copyright of their authors; see their repos for licence terms. Previews use a simplified mock of the T3 Code chrome, not the app itself.
