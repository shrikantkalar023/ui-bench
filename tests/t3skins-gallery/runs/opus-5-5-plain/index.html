Community skins · T3 Code

Every recent T3 Code skin, previewed live.

On 14 Nov 2026 at 9:41 AM IST, Theo announced that T3 Code can be fully restyled in-app, including custom CSS. This gallery compiles community skins shared in the days after that, from t3skins.dev, GitHub and X. Where a theme file is public, the card runs its real colours and CSS in a mock T3 Code UI, so animated skins actually animate.

Offline-friendly: open index.html from this folder. Install a skin in T3 Code via Settings → Appearance → Add, or t3 theme set file.json on the server. This is a personal compilation, not an official T3 product.

Install

How to install

  1. 1
    Download

    Download a skin’s JSON from its card or details view.

  2. 2
    Add it in T3 Code

    In T3 Code open Settings → Appearance, press Add, and drop the file in.

  3. 3
    Or use the server CLI

    On the machine running the T3 server you can also run:

    t3 theme set path/to/skin.json
  4. ↺
    Undo

    Built-in fallback:

    t3 theme set t3-chat
