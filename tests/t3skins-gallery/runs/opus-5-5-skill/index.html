Restyle T3 Code with a community skin

On 14 Nov 2026 at 9:41 AM IST, Theo announced that T3 Code can be fully restyled in-app, including custom CSS. This gallery collects 78 skins shared in the days after, from t3skins.dev, GitHub and X.

Where a theme file is public, each preview runs the skin’s real colours and CSS in a mock T3 Code window, so the 40 animated skins actually move.

    How to install

    1. Download a skin’s JSON from its card or its details view.

    2. In T3 Code, open Settings → Appearance, press Add, and drop the file in.

    3. Or, on the machine running the T3 server, run:

      t3 theme set path/to/skin.json

    To undo, pick another theme in Appearance, or go back to the built-in theme with t3 theme set t3-chat. This gallery works offline: open index.html from this folder.
